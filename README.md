# 4-Hands Timer

Адаптивные четырёхстрелочные спортивные часы (pace clock) для плавательных бассейнов.

## Как открыть

Откройте https://voodoo4815.github.io/4-hands-timer/ или `index.html` локально в браузере двойным кликом или:

```bash
open index.html
```

## Структура

| Файл | Назначение |
|------|-----------|
| `index.html` | SVG-циферблат с 60 делениями и 4 стрелками |
| `style.css` | Адаптивная вёрстка и CSS-анимация |
| `manifest.json` | Mанифест PWA |
| `sw.js` | Service Worker для офлайн-работы |
| `icon.svg` | Иконка приложения |

## Как работает

- **SVG** — круглый циферблат с 60 секундными делениями (12 длинных + 48 коротких) и 4 цветными стрелками в одной группе `<g id="hands">`.
- **CSS-анимация** — группа стрелок вращается как единое целое вокруг центра циферблата. Полный оборот за 60 секунд, линейная интерполяция, бесконечный повтор.
- **Адаптивность** — масштабирование через `vmin`, медиазапросы для мобильных (320px+), планшетов и десктопов.

## Установка как PWA

Откройте страницу в Chrome/Edge на Android или Safari на iOS:

- **Android** — «Добавить на главный экран» в меню браузера.
- **iOS** — «Поделиться» → «На экран "Домой"».

## Ограничения

- Минимальный JavaScript только для регистрации service worker.
- Нет полноэкранного режима.
- Нет предотвращения выключения экрана.
- Нет кнопок управления и настроек.
